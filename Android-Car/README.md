# JAMPlayer Car 1.0.6

獨立 Android 車機版，Android 8.0 以上可安裝。安裝識別 com.jayw.jamplayer.car，可與手機版 JAMPlayer 共存。

## 1.0.6 修正

- 將最低系統需求由 Android 12 降為 Android 8.0，修正 Android 10 車機無法安裝的問題。
- 保留原車機介面、記憶續播與手動休眠功能。

## 1.0.5 修正

手動休眠優先，最長 4 小時

- 手動休眠提供 15、30、45、60、90、120、180、240 分鐘，或自訂 1–240 分鐘。
- 有手動休眠時暫停背景一小時自動關閉限制，以手動時間為準。
- 回到前景、再切到背景、熄屏亮屏與切換曲目，手動休眠都沿用原到期時間，不重設、不歸零。
- 沒有手動休眠時，背景一小時開關照常生效；回到前景僅清除背景倒數。
- 背景取消手動定時，若背景開關開啟且仍在播放，從取消時重新倒數一小時；前景取消則不啟動背景倒數。
- 手動定時到期暫停後不重新啟動一小時倒數；車機亮屏／回到前景也不會自動重新播放，手動按播放可恢復。
- 通知欄與主 UI 使用同一個真正生效的倒數，12 種語言說明同步更新。

## 1.0.4 修正（歷史）

上下首與播放範圍修正

1. 主畫面上下首會切回正在播放的電台／最愛／本機／歌單，捲動到當前項目並高亮。超過 100 筆的清單會自動載入目標所在區段，單曲循環也會重新定位同一首。
2. 電台從「全部」開始播放，就依全部清單順序切換；從指定國家開始播放，只切換該國家；從最愛電台播放，依最愛電台順序切換。第一台與最後一台循環銜接。
3. 單純切換瀏覽分類不改變播放範圍；實際點播另一份清單的項目，才更新播放範圍。
4. 通知欄、Android 媒體控制／方向盤上下首沿用相同播放順序；背景切曲後回到畫面也會定位。未切曲時不會因定期更新把瀏覽位置拉走。
5. 快速點播再立刻切曲時，以最新的原生播放事件為準，避免舊連線等待或過期捲動覆蓋新焦點。
6. 車機保留左右 5:5 共用金屬框、可調清單字體與熄屏繼續播放。

## 1.0.3 修正（歷史）

- 關閉螢幕時繼續播放本機音樂與電台，只保存記憶，不主動暫停。
- 再次亮屏或回到前景時，若仍在播放就維持原播放器與位置，不重新開始或重連電台。
- 只有服務或程序已停止，才依自動續播開關於再次啟動時恢復。

## 1.0.2 修正（歷史）

- 左右各占一半，共用一個厚金屬外框，中央只有 1 px 細分隔線，沒有空隙或重複的金屬邊框，四角保留螺絲。
- 保留原有清單字體調整與 LED 自動縮放。

## 1.0.1 修正（歷史）

- 播放器與清單改為左 60%、右 40%。
- LED 時間與狀態資訊分欄，長時間與倒數數字依可用寬度縮放。
- 設定新增清單字體大小 14–28 px，預設 19 px，即時套用並保存至備份。電台、最愛、本機、歌單名稱與曲目說明隨之調整；圖示及索引維持原尺寸。

## 介面與操作

- 固定橫式、左右 5:5 雙欄，依視窗大小調整；左側播放面板，右側電台／最愛／本機／歌單／設定。
- 下方五個主功能使用大型金屬按鈕；設定時保留左側播放器。
- 電台清單沿用五個 GitHub 更新來源、國家分類、長按鎖定、索引編號、最愛保護與批量操作。
- 本機、最愛音樂與歌單各自保持播放範圍、循環／隨機模式；歌單可新增、改名、刪除，單選／多選加入。
- 保留三種配色、電台與音樂識別色、12 種顯示語言及資料備份匯入／匯出。
- 車機圖示在原金屬播放器上增加方向盤與琥珀邊框。

## 通電與 ACC 續播

1. 在車機系統把 JAMPlayer Car 設為自啟動或 ACC 喚醒時開啟的 APP。本 APP 不會自行修改車機設定，也不需要開機廣播或懸浮窗權限。
2. APP 進入前景後，預設等待 3 秒，自動恢復上次電台或本機歌曲。設定可關閉自動續播，或選擇 0／1／3／5／10／15 秒等待。
3. 電台重新連線直播；本機音樂接續保存的秒數，保留原歌單／最愛播放範圍。正在播放時再次啟動不會重頭播放。
4. 熄屏時保存並持續播放，亮屏且 APP 回到前景後不重啟正在播放的曲目或電台。若 ACC 深度休眠或重新開機使服務停止，則在車機系統再次開啟 APP 後，依設定恢復上次內容。
5. 播放中每 5 秒保存一次，暫停、切換來源、退到背景與正常停止服務時立即保存。突然斷電時，最多可能退回最近一次保存點附近；實際寫入仍取決於車機儲存裝置。
6. 網路或本機檔案尚未就緒時保留原目標等待，不擅自跳到別首。手動選曲／播放／暫停會取消正在等待的自動續播。
7. 電台來源本身失效時沿用連線逾時與重試提示，需手動更換可用來源。

車機版「背景一小時自動關閉」預設關閉，可在設定另行開啟；手動睡眠定時也保留。

## 手機資料轉移

在手機版設定匯出 JSON，在車機版設定匯入。電台、最愛、歌單、配色與語言沿用相同備份格式。

JSON 不包含音樂檔本身，也不能搬移另一台裝置的 Android 讀取授權。請先把音樂檔複製到車機或 USB 儲存裝置，再授予音樂權限並重新掃描。APP 私有 Music 裡的分享音樂需從原始來源重新傳送或匯入車機版。請不要刪除原始備份，直到確認曲目可播放。
