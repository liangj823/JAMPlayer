JAMPlayer Android 1.0.14 — 2026-11-22

手動休眠優先，最長 4 小時

- 手動休眠提供 15、30、45、60、90、120、180、240 分鐘，或自訂 1–240 分鐘。
- 有手動休眠時暫停背景一小時自動關閉限制，以手動時間為準。
- 回到前景、再切到背景、熄屏亮屏與切換曲目，手動休眠都沿用原到期時間，不重設、不歸零。
- 沒有手動休眠時，背景一小時開關照常生效；回到前景僅清除背景倒數。
- 背景取消手動定時，若背景開關開啟且仍在播放，從取消時重新倒數一小時；前景取消則不啟動背景倒數。
- 手動定時到期暫停後不重新啟動一小時倒數；車機亮屏／回到前景也不會自動重新播放，手動按播放可恢復。
- 通知欄與主 UI 使用同一個真正生效的倒數，12 種語言說明同步更新。


上下首與播放範圍修正

1. 主畫面上下首會切回正在播放的電台／最愛／本機／歌單，捲動到當前項目並高亮。超過 100 筆的清單會自動載入目標所在區段，單曲循環也會重新定位同一首。
2. 電台從「全部」開始播放，就依全部清單順序切換；從指定國家開始播放，只切換該國家；從最愛電台播放，依最愛電台順序切換。第一台與最後一台循環銜接。
3. 單純切換瀏覽分類不改變播放範圍；實際點播另一份清單的項目，才更新播放範圍。
4. 通知欄、Android 媒體控制／方向盤上下首沿用相同播放順序；背景切曲後回到畫面也會定位。未切曲時不會因定期更新把瀏覽位置拉走。
5. 快速點播再立刻切曲時，以最新的原生播放事件為準，避免舊連線等待或過期捲動覆蓋新焦點。
6. 車機保留左右 5:5 共用金屬框、可調清單字體與熄屏繼續播放。
